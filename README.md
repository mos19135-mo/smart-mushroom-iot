## ⚙️ คุณสมบัติของระบบ (Key Features)
- **Closed-Loop Automation:** ควบคุมปั๊มพ่นหมอกตามความชื้นอากาศและก้อนเพาะ, พัดลมระบายอากาศตามอุณหภูมิ, และสเปรย์หล่อเย็นอัตโนมัติ
- **Dry-Run Protection:** ตรวจสอบระดับน้ำในถังด้วยสวิตช์ลูกลอย ตัดการทำงานของปั๊มทันทีเมื่อน้ำหมด
- **Safety Interlock & E-STOP:** ตัดวงจรโหลดทั้งหมด 100% ทันทีเมื่อกดปุ่มหยุดฉุกเฉิน ทั้งจากบอร์ดจริงและหน้าเว็บ
- **Dual Mode Control:** สลับการทำงานระหว่างโหมด AUTO (ตัดสินใจอัตโนมัติ) และ MANUAL (สั่งงานผ่านเว็บ)

## 🔌 การเชื่อมต่อขาอุปกรณ์ (ESP32 Pinout)
| อุปกรณ์ | ขา ESP32 | หน้าที่ |
|---|---|---|
| **DHT22** | GPIO 15 | วัดอุณหภูมิและความชื้นสัมพัทธ์ในอากาศ |
| **Moisture Sensor** | GPIO 35 (ADC) | จำลองความชื้นวัสดุเพาะเห็ด |
| **LDR Sensor** | GPIO 34 (ADC) | ตรวจวัดความเข้มแสง |
| **Float Switch** | GPIO 4 | สวิตช์ลูกลอยระดับน้ำถังพ่นหมอก |
| **Emergency Pushbutton**| GPIO 21 | ปุ่มกดหยุดฉุกเฉิน (E-STOP) |
| **Relay ปั๊มพ่นหมอก** | GPIO 2 | ควบคุมการพ่นหมอกเพิ่มความชื้น |
| **Relay พัดลมระบายอากาศ**| GPIO 13 | ระบายความร้อนและอากาศ |
| **Relay สเปรย์หล่อเย็น** | GPIO 14 | ลดอุณหภูมิกรณีวิกฤต |
| **Siren LED / Alarm** | GPIO 12 | ไฟเตือนสภาวะฉุกเฉิน |
